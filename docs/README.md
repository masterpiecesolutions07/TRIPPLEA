# Tripple A documentation

This folder is the reference for the mentorship platform. The requirements text calls the brand "Triple A". The logo spells **Tripple A**, and that is the name used in the product.

Read the files in order when you are building a feature. Each file stands on its own.

| File | Use it when you are working on |
| --- | --- |
| [01-overview.md](01-overview.md) | Purpose, facts, and what this version does not include |
| [02-roles.md](02-roles.md) | Who can do what |
| [03-site-map.md](03-site-map.md) | Public pages and the three dashboards |
| [04-auth-and-seeding.md](04-auth-and-seeding.md) | Accounts, passwords, and the first admin |
| [05-cohorts-and-applications.md](05-cohorts-and-applications.md) | Intake, cohorts, and the waitlist |
| [06-content.md](06-content.md) | Certificates, trades, alerts, stories, contact |
| [07-dashboards.md](07-dashboards.md) | Student, mentor, and admin screens |
| [08-api-and-data.md](08-api-and-data.md) | Collections and `/api/v1` routes |
| [09-design.md](09-design.md) | Colour, type, icons, and layout |
| [10-security-legal-milestones.md](10-security-legal-milestones.md) | Safety, disclaimer, and build order |

## Current build

The React site, JWT register and login, contact messages, admin seeding, and the three dashboards are in the repo. Email delivery, Cloudinary uploads, and payments are specified here and are not connected yet. Do not invent contact details, profit numbers, or testimonials to fill those gaps.
